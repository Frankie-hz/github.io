## Adding More Guides

1. Create a new file under `guides/`, for example `guides/my-new-guide.md`.
2. Start it with a title:

   ```md
   # My New Guide
   ```

3. Link it from this page and from `guides/index.md`.
4. After GitHub Pages publishes, the page URL will match the folder path. For example, `guides/my-new-guide.md` becomes `guides/my-new-guide.html`.
